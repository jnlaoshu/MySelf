## 📌 使用说明

1. 根据您使用的客户端（Clash Party 或 Clash Verge）选择对应的配置文件。
2. 将 `Profile.yaml` 下载到本地，导入客户端即可（建议先备份原有配置）。
3. 规则文件位于 [`Rules/`](./Rules) 目录，可自行引用。

> ⚠️ **注意**：配置文件中的代理节点、策略组等均为个人设置，请根据您的订阅和网络环境调整。
